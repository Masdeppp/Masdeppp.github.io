## Konteks

Capstone project Bangkit Academy 2024 Batch 2, dikerjakan tim lintas jalur selama
fase capstone. Repositori tim terbagi tiga: `MLTrain` (model + API prediksi),
`akun-management`, dan `android-api`.

Saya sebagai Machine Learning bertanggung jawab untuk melakukan data scraping, 
data preprocessing, data training, model evaluation, dan deployment model ke Cloud Run.

## Masalah

Banyak orang ingin mencapai berat badan yang ideal namun tidak mengetahui faktor-faktor
yang memengaruhi berat badan mereka, ataupun bagaimana cara mencapai berat badan yang ideal. 

## Pendekatan & Keputusan Teknis

Model TensorFlow memetakan **18 fitur** gaya hidup ke **7 tingkat obesitas**,
dibungkus sebagai REST API dan dideploy ke Cloud Run.

- **Tiga kelompok fitur** — demografi & fisik, kebiasaan makan, dan perilaku
  harian (aktivitas, asupan air, transportasi)
- **Tiga endpoint** — `GET /` status, `POST /predict` klasifikasi,
  `GET /predict/{id}` ambil riwayat
- **Setiap prediksi disimpan ke Cloud SQL** — memberi pengguna riwayat, dan
  memberi tim data nyata untuk melatih ulang model

## Hasil

Model menggunakan RandomForestClassifier dengan akurasi 0.953 pada data uji
yang merupakan akurasi tertinggi dibandingkan algoritma lainnya seperti 
KNeighborsClassifier, SVC, DecisionTreeClassifier, AdaBoostClassifier,
GradientBoostingClassifier, dan SGDClassifier.  

Proyek capstone, tidak dirilis ke publik.
